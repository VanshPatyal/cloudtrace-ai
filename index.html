Developer Integration

One Line of Code Telemetry

Wrap your existing agent framework (LangChain, AutoGen, CrewAI, or custom SDK) with lightweight decorators. 


// Initialize CloudTrace AI on Azure Environment
import { CloudTrace } from "@cloudtrace/agent-sdk";

const tracer = new CloudTrace({
  apiKey: process.env.CLOUDTRACE_AZURE_KEY,
  environment: "sandbox",
  redactSensitiveData: true
});

// Wrap your autonomous LLM Agent loop
const agent = tracer.wrapAgent(async (context) => {
  const plan = await agent.think("Architect", context.prompt);
  const toolResult = await agent.executeTool("WebSearch", plan.query);
  return await agent.synthesize(toolResult);
});
